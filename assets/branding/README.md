# Application artwork

`apk-runner-logo.png` is the rounded transparent artwork. `apk-runner.ico` contains 16, 24, 32, 48, 64, 128 and 256 px frames with transparent corners. Both are embedded by the application and used for Windows icons/packaging.

The existing artwork was created/edited with image generation at the author's direction and is offered under this repository's MIT License. External marks and third-party software retain their own rights.

See [the build guide](../../docs/BUILDING.md) for import and verification commands. The README hero image in `docs/images` is separate from the app icon.
