# Security reporting

APK Runner processes local Android packages and starts third-party tools. Use APKs from sources you trust. Emulation is not a claim that an untrusted app is harmless to your PC or accounts.

If the repository's **Security** tab offers private vulnerability reporting, use it. Otherwise, open an issue containing only a general request for a private reporting channel; do not post exploit details, credentials, or vulnerable user files. A dedicated private channel and response-time commitment are not currently established.

A private report should include affected version, reproduction steps, impact, and a minimal example you have the right to share. Never include keys, tokens, installed-app data, or virtual-device disks.

Development builds and forks need their own explicit update-source and signing policy; see [BUILDING.md](docs/BUILDING.md).
